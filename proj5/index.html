Part 1: Sampling Loops and Diffusion-Based Editing

1.1 Implementing the Forward Process

I implemented the forward diffusion process that maps a clean image \(x_0\) to a noisy image \(x_t\) using the precomputed cumulative noise schedule \(\bar{\alpha}_t\). I applied this to the Berkeley Campanile image at several timesteps.

Observations

  • Noise visibly increases as \(t\) grows, while structure gradually disappears.
  • At high timesteps, the image is close to pure Gaussian noise.

1.2 Classical Denoising (Gaussian Blur)

Using Gaussian blur as a classical baseline, I attempted to denoise the noisy Campanile images from Part 1.1. It partially removes high-frequency noise but also severely blurs edges and textures.

Takeaways

  • Gaussian blur smooths noise but also obliterates fine detail.
  • Heavier noise levels require stronger blur, which further degrades structure.

1.8 Visual Anagrams

I implemented a visual anagram sampler that averages two guided noise estimates: one for a prompt \(p_1\) on the original orientation, and one for a prompt \(p_2\) on a flipped version of the current image. The result is an image that looks like one prompt upright and another when flipped upside down.

1.9 Hybrid Images

For hybrid images, I combined low-frequency components of one prompt-guided noise estimate with high-frequency components of another. After denoising, the resulting image behaves like a hybrid: one concept dominates at close range and another at a distance.
