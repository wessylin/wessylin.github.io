Project 5 (Part A): The Power of Diffusion Models

Part 0: Setup

Overview

In this project, I experiment with pre-trained diffusion models using the DeepFloyd IF Stage I model. I implement forward and reverse diffusion processes, build sampling loops, and apply them to tasks such as denoising, sampling from noise, image-to-image editing, inpainting, and creating optical illusions like visual anagrams and hybrid images.

Part 0.1: Gaining Access to DeepFloyd

I first set up the environment needed to run DeepFloyd IF by installing all required packages in Google Colab (including Diffusers, Transformers, Mediapy, and Accelerate), and configured my device to use CUDA. I then loaded the two DeepFloyd IF stages from HuggingFace using half-precision (fp16) weights to fit within GPU memory. Stage I produces 64×64 image latents, and Stage II upscales them to 256×256. Both models were moved to the GPU for faster sampling.

Part 0.2: Playing with Text Prompts

Before generating images, I loaded my prompt embeddings from the provided .pth dictionary and inspected the available text prompts. Using these embeddings, I sampled images from Stage I and Stage II with a fixed random seed (seed = 100) to ensure reproducibility. I experimented with different denoising budgets—starting with num_inference_steps = 20 for fast results and later increasing to 40 for higher-quality generations. This helped me understand how the prompt conditioning and step count influence the final image quality.
