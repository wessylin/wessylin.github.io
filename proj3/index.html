Project 3: [Auto]Stitching Photo Mosaics

Part A: Image Warping and Mosaicing

Overview

In Part A of this project, I build image mosaics by estimating planar projective transforms and use them to warp and composite overlapping photos. Using fun photos captured in my day-to-day, I recover homographies H from clicked correspondences (DLT), then apply inverse warping with both nearest-neighbor and bilinear interpolation. I also explore rectification by mapping a slanted plane to a fronto-parallel view, before blending the aligned images into seamless mosaics.

Part A.1: Shoot the Pictures

In this project, I capture overlapping views of a scene and align them using planar homographies. Each image is warped into a shared reference frame and blended to produce a seamless mosaic.

Part A.2: Recover Homographies

In Part A.2, I recover the homography (H) that maps points from Image A to Image B using the Direct Linear Transform (DLT). Starting from the homogeneous relation x′ ∼ Hx and writing it in inhomogeneous form, each correspondence (x, y) → (u, v) yields two linear constraints after clearing the denominator. I stack these into a 2N × 9 system Ah = 0 with unknowns h = vec(H).

Concretely, for each pair, I add the “u” row [−x, −y, −1, 0, 0, 0, ux, uy, u] and the “v” row [0, 0, 0, −x, −y, −1, vx, vy, v]. I build these rows efficiently with vectorized slices so every other row corresponds to the same point.

System size: A ∈ ℝ16×9 (two rows per correspondence).

Because Ah = 0 is homogeneous, I solve for the right singular vector of A with the smallest singular value (via SVD), reshape it to 3×3, and fix the scale by setting H33 ≈ 1. I then visualize the clicked points side-by-side with connecting lines to confirm consistent ordering and good spatial coverage, both of which are important for numerical stability.

I use no normalization here. In practice, adding Hartley normalization or RANSAC improves robustness, but for this part, the plain DLT with N ≥ 4 clean, well-distributed correspondences recovers a valid H and clearly demonstrates the setup, system Ah = 0, and final matrix. We will, however, explore normalization later in this project.

Part A.3: Warp the Images

I performed inverse warping by mapping each output pixel back through H^{-1} to source coordinates and sampling with bilinear interpolation. The output canvas bounds were determined by transforming the source corners and taking the axis-aligned hull.

Part A.4: Blend the Images into a Mosaic

I composited warped images on a shared canvas using feather blending within overlap regions. Optionally, multi-band (Laplacian pyramid) blending further reduces visible seams.
